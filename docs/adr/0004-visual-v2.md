# ADR-0004 视觉第二版（v2）

- 状态：已采纳（2026-11-16）
- 背景：用户反馈 v0.3 首版界面偏冷、偏挤、顶栏空。参考方向仅为旧版截图的**视觉风格**（未查看、未复制旧仓库代码或 CSS），设计令牌在本仓库重新编写。

## 决定

1. 令牌重写（`apps/web/src/styles.css`）：暖中性石色底（hue≈75–85、极低彩度），主色改为低饱和鼠尾草绿（替代偏冷青绿）；信号色整体降饱和；新增 `--avatar` / `--avatar-foreground`（浅色圆底头像）。深色模式同样保持暖调。
2. 标签页选中态：去掉粗描边/阴影，改为柔和底色填充（`bg-accent`）。
3. 字号/行距：正文 14.5px、行高 1.6；消息正文 1.7 行高；消息组间距由 `pt-2.5` 增至 `pt-4`，头像 36px。
4. 去掉顶栏：搜索（⌘K）移到侧边栏顶部；用户、主题、折叠移到侧边栏底部；会话头部一行包含群名、"项目主群 · N 位成员 · M 个 Agent · 按 seq 排序"与消息搜索框。
5. 右侧面板：分节小标题 + 彩色圆点（决策=绿、未决问题=琥珀、约束=蓝、风险=红；任务按状态色分节；成员/Agent 分节），空状态为安静的灰底提示。
6. 线程回复折叠：主时间线只保留线程根消息并显示"N 条回复 · 查看线程"；明确跳转到某条回复（`seq` 参数）时该回复仍可见。
7. 演示数据：`bun run --cwd apps/server seed:demo`（`src/cli/seed-demo.ts`）生成"支付服务（演示）/DEMO"项目，所有内容标注【演示数据】。决策卡因决策 API 属 S4，暂由服务层直接写入；其余全部走公开 HTTP API。

## 影响

- 截图：`screenshots/chat-v2-*`、`chat-tasks-v2-*`、`project-home-v2-*`（`e2e/s2b-visual-v2.spec.ts`）。
- 右栏"摘要/决策"在 S4 前从已加载时间线中的决策卡汇总，非独立 API。
