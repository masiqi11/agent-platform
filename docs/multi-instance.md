# 多实例部署：正确性清单（§11.5）

本文逐条核对 §11.5 的多实例要求：要么有测试证明，要么写明限制。核对时间为 2026-11-17（S8）。

## 结论

可以同时运行**多个 `ROLE=api` 实例和多个 `ROLE=worker` 实例**，条件是：

- 所有实例共享**同一个 `DATA_DIR`**：同一台主机，或者用共享卷（NFS 等）。
  - 工作区、仓库镜像缓存，以及本地对象存储（`OBJECT_STORE=local`）都在 `DATA_DIR` 下。
  - 一个任务的工作区可能由不同的 worker 接着处理，所以这一点是硬性前提。
- 不使用本地 Git 服务（`LOCAL_SCM_DIR`，只用于演示），而是接 GitLab。

不满足这两条时，只能**单实例部署**（`ROLE=all`）。

## 已修复的问题

worker 停止时原来**总是**要等满 10 秒：恢复循环每 15 秒轮询一次，`stop()` 要等所有循环醒来。这样每次发布都白等 10 秒；而 docker 默认的 SIGKILL 期限也是 10 秒，长作业会被杀在半途。现在轮询循环在停止时立即被唤醒；等待时长可通过 `SHUTDOWN_GRACE_MS` 配置，并与编排器的 kill 超时对齐。
