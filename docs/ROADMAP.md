### P1-02 · P1：Job 单调围栏与自动续租

**已合入** `f02e7f0`：

- 每次领取写入新的 `lease_token`。它是随机令牌，不是递增版本，但同样能让旧持有者的写回失败。
- 所有状态写回都要求令牌匹配。
- 按租约的 1/3 自动续租。
- 失租或超时时，通过 AbortSignal 通知 handler。
- 回归测试在 `kernel.test.ts`。

- [x] 在 `core/jobs.ts` 及 schema 引入每次领取原子递增的 `lease_version`，返回 owner 与版本；统一所有续租、成功、失败、重试、取消写回条件。
- [x] 写回校验 job id、owner、lease_version、运行状态及有效租约；过期租约不能被旧 Worker 续活。60 秒默认租约可每 20 秒续租，但实际周期从租约长度推导并支持短租约测试。

## 5. Phase 3：S7+ 检索、安全与记忆

依据 [ADR-0008](adr/0008-s7-knowledge-base.md) 的已知局限推进；[ADR-0009](adr/0009-real-model-claude-opus.md) 仅作为仓库历史模型评测来源。

- [ ] **AST 与依赖图（FR-KB-02）**：评估 web-tree-sitter，按函数/类/接口边界切分并带作用域签名；超长节点仍受 token 限额约束，解析失败可观测回退。提取 import/export、符号引用和变更影响关系；按源语言明确覆盖范围。
- [ ] **冷层索引**：同步 GitLab Issue、MR 讨论和关键提交说明，保留来源、版本、ACL、删除/权限撤回传播；不将外部内容升级为系统指令。
- [ ] **嵌入模型版本化**：按模型、维度、索引版本隔离，支持 1024 维等新模型；离线重建、原子切换、回滚与迁移预算。不同模型即使同维也不得混检，不直接原地改列维度破坏在线索引。
- [ ] **Cross-Encoder 重排**：三路粗排后评估 bge-reranker-v2-m3 等候选，测精度、延迟与成本；项目先验抑制跨域误引。重排分数不是经过校准的置信度，只有验证集证明改善并通过 ADR 评审后才调整“纯向量不算证据”规则；ACL 前置、引用来源校验和无证据拒答保留。
- [ ] **长期记忆（KB-补7）**：条目带来源、作用域、时间、版本与订正记录；支持衰减、撤销、删除传播和人工纠正，避免过期假设成为事实。
- [ ] **间接注入治理**：对代码注释、文档、Issue/MR 等标记不可信边界，结合模式扫描与工具执行层授权、参数校验、出域策略；关键操作保持原有审批。提示词过滤不能替代权限边界。
- [ ] **评测（FR-KB-11）**：每项目至少 100 题，覆盖调用链、ADR、跨项目区分、无证据拒答；分离调参与保留测试集，记录标注版本、模型和索引版本。输出 Recall@5、Citation Precision、跨项目错误引用率、注入攻击成功率及正常请求误拒率。

准出目标：Recall@5 ≥ 0.90；跨项目错误引用率 < 3%（错误项目引用数 / 全部跨项目回答引用数，零引用回答另计拒答率）；固定注入测试集成功越权为 0，同时公开样本数与误拒率。“测试集 100% 拦截”仅限该版本测试集，不构成通用抗注入保证。

## 7. 执行与证据管理
